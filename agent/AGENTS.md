# Agent 服务工作边界

- 本目录是独立智能体服务，不能并入业务后端进程，也不能由 Android APP 直接调用。
- 当前仅 F08 冻结快照分析任务按本仓代码与测试作为已接入能力；F09 独立回调、F03/F04 图片候选回调等仍按主仓验收状态处理，不因本目录代码存在而视为完成。
- 默认运行模式必须为 `mock`，用于离线协议开发；不得把 mock/replay 结果描述成当前真实模型推理结果。
- Agent 只能接收业务 Worker 按任务授权提供的冻结快照，并通过内部接口提交结构化结果。不得按患者查询历史、访问业务数据库、写业务表或管理业务任务状态。
- `gutcare_agents` 内的 SQLite 仅用于 Agent 服务自身的开发期任务/派发状态，不能作为业务库或患者数据源。
- 主仓 `contracts/agent/agent-v1.yaml`、已采纳 ADR 及主仓文档是业务接口语义的权威来源。`docs/后端契约参考_固定版本/` 是源仓随附参考副本，不得据此覆盖主仓契约。
- 不提交密钥、服务令牌、真实患者数据、模型原始输出或生成的 SQLite 数据库。容器启动必须由操作者显式提供 `GCA_INTERNAL_TOKEN`。
- 风险规则未经专业审核只能标记为 `test_only`；不得生成诊断、处方修改或药物剂量调整。
