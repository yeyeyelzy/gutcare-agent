# Android 非智能体功能迁移与验收缺口清单

> 基线：仓库提交 `316de37`（2026-10-20）。本清单只记录原生 Android 客户端在非智能体业务上的迁移、调试和测试缺口；后端 `verified` 只表示后端自己的门禁通过，不代表 Android 页面已接入或端到端通过。
> 权威状态仍以 [Android 页面—功能—API—测试映射](Android页面-功能-API-测试映射.md)、[需求追踪矩阵](需求追踪矩阵.md)、[测试方案](测试方案.md) 和对应 ADR/契约为准。本清单是便于排查和排期的汇总。

## 判定口径

- **已迁移且有联调证据**：原生页面/Repository 已连接真实业务 API，且有模拟器或隔离演示环境证据。限定到列明的子范围。
- **未完整迁移**：原生端缺页面、数据接线或用户操作闭环；后端已实现不改变此状态。
- **代码存在但未完成真实调试/E2E**：有 route、页面、ViewModel 或契约测试，但尚未以真实后端路径完成端到端验证。
- **测试受条件限制**：测试要求独立 PostgreSQL/MinIO/ClamAV、专用凭据或设备能力；条件不具备时被跳过，跳过不算通过。
- **排除项**：由独立智能体服务完成的分析、识别或回调能力，不列为本客户端非智能体完成项；与其相邻的业务端授权、任务、候选审核和安全边界仍需按各自契约验收。

## 条件跳过与尚未通过的验收

1. **独立 PostgreSQL 18 集成测试**：测试要求专用测试数据库、应用/迁移角色及专用 URL；相关测试在未配置环境时会主动 skip。必须按 `docs/测试方案.md` 的隔离约束运行并保存报告，才能将对应数据库/权限/迁移用例记为通过。
2. **MinIO/ClamAV 集成**：部分 F02、F03/F04 文件和 worker 测试需要隔离 MinIO 与 ClamAV。当前 F02 phone-demo 文件服务 E2E 已有证据，但不能据此宣称其他全部文件、worker、删除恢复和记录图片用例通过。
3. **Android opt-in live 测试**：phone-demo live contract 测试依赖本机服务、演示邮箱及启动参数；普通 CI/本地默认套件跳过它们时，只能记为常规自动化通过，live 项按单独证据记录。
4. **视觉验收**：标准为每页至少 80% 且无明显视觉错误。现存分数（含 F06/F10/F11 探索分数）只作方向性检查；没有完整截图、采集记录及系统栏/安全区对齐证据时不得标为通过。
5. **真机与发布**：当前模拟器证据不替代真机测试；注册告知生产签核、Android 安全存储设备行为及文件保存分享能力仍是相应发布门禁。

## 独立智能体范围（不计入非智能体迁移完成项）

- **F08 Agent 执行和回调**：真实 Worker/Agent 领取任务、读取冻结输入、分析、提交结构化回调、结果持久化与查询的端到端链路由智能体服务团队负责。Android/业务后端不得直连 Agent；F08 后端 verified 不证明 Agent 服务或跨团队 E2E 已完成。
- **F02 文档解析/候选生成**：解析推理与 Agent 候选 callback 属于 Agent 执行范围；业务后端授权 fence、候选存储/决定 API，及 Android 候选审核页面仍各自按上表验收。`store_only` E2E 不代表 analyze 或候选链路通过。
- **F03/F04 图片识别**：识别推理及识别候选 callback 属于 Agent 范围；Android 的 purpose-specific 授权、上传/关联、候选逐项决定与业务 API 联调不是 Agent 自动完成，仍需单独验收。
- **F09 建议生成**：建议内容生成属于 Advice Agent；业务 API 的读取、反馈、生命周期和 Android 页面接入仍属相应非 Agent/客户端缺口。

不得以合成候选、固定演示结果、旧 `app/` 归档测试或后端单测代替上述真实跨服务证据。
