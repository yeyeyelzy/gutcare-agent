# ADR-0003：采用 PostgreSQL、MinIO/S3 与 Redis 的存储组合

- 状态：Accepted
- 日期：2026-10-14

## 决策

`gutcare_business` 使用 PostgreSQL 18.x 保存权威业务状态；私有二进制存 MinIO Community；Redis 仅用于缓存、限流、锁与 Celery Broker。智能体知识库为独立 `gutcare_knowledge` PostgreSQL 数据库并使用 pgvector 0.8.7+。MinIO 镜像从官方源码的审核 commit 自行构建并锁定 digest，不使用已停止维护的历史预编译二进制。

## 理由与后果

关系约束、事务、RLS、JSONB 与版本证据适合业务数据；对象和短期队列不应挤入主库。Redis 丢失不得造成权威数据丢失。知识库由智能体团队独立迁移和授权，即使共用集群也不得共库。

依据：<https://www.postgresql.org/support/versioning/>、<https://github.com/pgvector/pgvector>
