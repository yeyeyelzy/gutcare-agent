# ADR-0002：业务后端采用 FastAPI 模块化单体

- 状态：Accepted
- 日期：2026-10-14

## 决策

非智能体业务后端采用 Python 3.13、FastAPI、Pydantic v2、同步 SQLAlchemy 2.1/psycopg 和 Alembic 的模块化单体。模块按业务域隔离，通过 Application Service 与 Unit of Work 协作。

## 理由与后果

当前规模不需要微服务治理；单体可保持患者记录、任务、证据与 Outbox 的本地事务。禁止跨模块直接操作他域 Repository，未来只有经指标证明的独立扩缩容需求才拆分服务。
