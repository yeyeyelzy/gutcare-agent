# GutCare 比赛本机演示手册

> 建议时长：10–12 分钟。以 Android 原生 APP 为主；服务端或 Agent 无法现场稳定复现时，用脱敏证据卡说明范围。状态以本手册所列文档和证据为准，不能把页面已实现、mock、单次 live smoke 或构建通过说成完整验收。

## 演示素材与安全规则

- 素材目录：`demo-materials/competition-demo/`。其中 `synthetic-medical-report.pdf`、`synthetic-meal.png`、`synthetic-stool.png` 和 `manual-input-examples.json` 均已生成；三个上传文件已同步到模拟器 `Download/GutCareDemo`。
- 本机私密卡：`.demo-output/competition-demo/account-card.txt`（Git 已忽略）。卡片内的“未注册账户”用于注册演示，“预置记录账户”用于登录演示；两个账号和密码彼此独立。脚本会为预置账号通过固定幂等键准备饮食、排便、症状各 3 条合成记录；重复运行不会重复新增。心情记录只有在演示账号本人已明确授予心情数据处理授权时才写入，不由脚本替用户授权。密码只在输入前临时复制，不入镜、不口播。
- 全程不得展示 Token、验证码、报告正文、永久 URL、完整 prompt/模型原始输出、真实身份或真实健康信息。预览文件只用短时授权入口；录制时隐藏网络面板、调试日志和系统通知。
- 合成注册字段示例：邮箱 `gutcare.register.demo+20261022@example.test`；昵称 `演示用户甲`；出生年份 `1990`；时区 `Asia/Shanghai`；隐私告知与健康数据处理告知分别阅读并明确同意；密码从私密卡的“未注册账户”区块复制。若该邮箱已被使用，先把邮箱日期后追加一位序号并同步更新私密卡；不要复用预置记录账户。
- 预置记录账号登录后已有饮食、排便、症状各 3 条脚本种子记录，可直接展示列表与历史读回。心情数据需要本人先在 APP 中明确授权；授权后重跑脚本即可幂等补齐 3 条心情记录。若现场要新增手工记录，示例以 `manual-input-examples.json` 为准。不要把示例描述成医学判断。

## 录制前 10 分钟准备

1. 启动 Docker Desktop，等待左下角显示引擎可用。
2. 在仓库根目录打开 PowerShell，运行 `./scripts/phone-demo-up.ps1`，看到 API、数据库、Redis、Mailpit 均健康后继续。
3. 运行 `./scripts/prepare-competition-demo-account.ps1`。它会为“预置记录账户”重置本机随机密码、验证登录、按固定幂等键准备饮食/排便/症状各 3 条合成记录，并生成被 Git 忽略的本机私密卡；不会在终端输出密码或令牌。心情种子仅在本人已授权时补齐；活动和用药计划不由此脚本初始化。
4. 在 Android Studio 打开 **Tools → Device Manager**，启动 `GutCare_API_37`。模拟器应出现在右侧 **Running Devices** 面板。若成为独立窗口，进入 **Settings → Tools → Emulator**，勾选 **Launch in the Running Devices tool window** 后从 Device Manager 重启。
5. 确认模拟器文件选择器的 **Download → GutCareDemo** 下有三个上传素材。若模拟器被重建，重新推送素材：

   ```powershell
   $adb = 'D:\Android\Sdk\platform-tools\adb.exe'
   & $adb shell mkdir -p /sdcard/Download/GutCareDemo
   & $adb push '.\demo-materials\competition-demo\synthetic-medical-report.pdf' '/sdcard/Download/GutCareDemo/'
   & $adb push '.\demo-materials\competition-demo\synthetic-meal.png' '/sdcard/Download/GutCareDemo/'
   & $adb push '.\demo-materials\competition-demo\synthetic-stool.png' '/sdcard/Download/GutCareDemo/'
   ```

6. 关闭 Android Studio 的 Logcat、Build 和终端面板；关闭桌面通知；把 Running Devices 面板放大到观众能看清文字。先完成一次不录制彩排。

## 手工输入速查

- 注册：邮箱见私密卡“未注册账户”；昵称 `演示用户甲`；出生年份 `1990`；时区 `Asia/Shanghai`；密码从该区块复制。
- 饮食：午餐；`合成米饭`（一小碗）与 `合成蔬菜`（一份）。
- 排便：Bristol 4；不填血便、紧迫度和备注。手工记录与 AI 图片分类是两个不同流程。
- 症状：腹胀；轻度（2）；持续 20 分钟；状态“已缓解”。
- 心情：4；标签“平静、满足”；备注留空。
- 活动：步行；低强度；15 分钟；主观感受“无明显变化”。
- 用药：名称 `合成演示片剂`；只展示计划和待打卡状态，不填写剂量，不描述处方调整。
- 医疗报告、餐食图片、排便图片：在文件选择器进入 **Download → GutCareDemo**，选择与页面对应的文件。
