# 文档一致性修订记录

## 2026-10-14 · 基线 V1.1

本次修订完成以下统一：

- 将原设计中的响应式 Web/浏览器语义全部改为 Android/iOS APP 语义。
- P0 认证固定为邮箱 + 密码 + SMTP；手机号/SMS 移出 P0。
- 患者资料最小化为可选昵称与必填出生年份，移除完整生日、性别、身高、体重基线字段。
- 用药计划拆分确认状态和执行状态。
- HTTP 成功响应与 RFC 9457 错误响应不再使用模糊“统一包裹”。
- 统一 Agent 路径为 `/internal/v1`、参数为 `snake_case`，明确 Worker 唯一 claim。
- 业务库与智能体知识库按数据库和角色隔离。
- 增加证据原文定位字段，并明确源记录删除后的历史证据行为。
- 冻结单记录、注销、备份与审计的生命周期时限。
- 补充文档索引、数据字典、隐私、医疗安全、测试、运维、UI、追踪矩阵、ADR 与 OpenAPI 契约。

核验来源包括 DCloud/uni-app、Node.js、PostgreSQL、pgvector、RFC Editor、国家网信办/中国政府网及 NIDDK 的官方资料。医学来源仅形成候选审核范围，未直接转成生产临床规则。

- 采纳 ADR-0019，新增 F14 心情记录业务闭环，并同步 APP/业务后端责任边界、数据库模型、数据字典、状态机、隐私生命周期、技术与开发实施方案。
